# FDSN Event Fetcher GUI

## Description
A PyQt5-based GUI application for fetching and saving seismic events from FDSN Web Services.

## Features
- Fetch events from multiple FDSN data centers
- Filter events by time range and minimum magnitude
- Save events in multiple formats (QuakeML, CSV, ZMAP, NORDIC, etc.)
- Support for additional event metadata

## Dependencies
- Python 3.x
- PyQt5
- ObsPy, 
- pandas

## Installation
1. Clone the repository
2. Install required dependencies:
- pip install PyQt5 obspy pandas
